## MultiZone v0.21.1

Saved runs you can write and share, a lighter thread, and a long list of fixes found by running every feature end to end.

### Saved runs
- **Settings → Saved runs**: write a run as a prompt with `{{blanks}}`, give each blank a default, and pick the zone it runs in. A blank with no parameter is offered as a one-click row.
- **Share a run as one file**: Export saves a `.run.json`; Import adds it under a free name.
- Running a saved run from **Ctrl+K** asks for its parameters first, each filled with its default. Saved runs are also in the **/** menu.

### Faster
- Long chats scroll more smoothly: turns that are off screen skip layout and paint, and Mermaid diagrams draw only as they come into view, one per frame.

### Fixed
- **Browser and phone:** editing a provider, zone, project, skill, memory, MCP server, run or schedule failed with "Not saved". It saves again.
- **Forks:** forking a continuation "with branches" could crash the app; a fork no longer carries sub-agent runs started after the point you forked at.
- **Plans:** an approved plan now reaches the turn that carries it out, Stop after this step works, and a running turn hears about edits you make to its plan. Revert is offered again on a primary answer's turn.
- **Files and paths:** an approved absolute path outside the allowed folders is refused, not quietly written inside the project. Listing a large folder no longer stalls the app.
- **Skills:** a skill whose name has spaces can be invoked as one `/word` (`Release notes` → `/Release-notes`). A `/skill` in a queued message still loads.
- **Keyboard:** F6 and Ctrl+Shift+Enter leave an open model list alone, and Ctrl+F on the Settings tab no longer reaches past an open dialog.
- **Search:** jumping to a result works with other chats open and lands on the message.
- **Chats:** a title you set is no longer replaced automatically, and a chat is still named when the title request fails. A deleted chat's cached state is cleared.
- **Display:** long URLs and identifiers wrap instead of being clipped; a folder dropped mid-sentence gets one space either side; a pane's active tab stays in view; a fresh install docks both side panels.
- **MCP:** a server's start error shows in its row, not only on hover.
- **API:** a `?wait=true` turn finishes even if the caller hangs up.

### Installing
| Installer | Description |
|-----------|-------------|
| `*_x64-setup.exe` | Windows installer |
| `MultiZone-*.apk` | Android — a remote for your computer, not a second app. Pair it under Settings → Phone & remote. |

Existing installs update themselves — see Settings → Data → Updates.
