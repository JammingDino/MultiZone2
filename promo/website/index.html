The zone

definition

A zone is an instrument, not a dropdown.

Every other client asks you to pick a model. A zone carries five things at once, which is why two zones on the same model are two different players.

  1. 01

    Provider

    Any OpenAI-compatible endpoint. A frontier API, a self-hosted server, LM Studio on your own GPU. You supply the URL and the key.

  2. 02

    Model

    Whatever that provider serves. Nothing is bundled and nothing is proxied — MultiZone talks to the provider directly.

  3. 03

    System prompt

    The part that makes two zones on one model genuinely different players — a reviewer, a scout, a devil's advocate.

  4. 04

    Temperature

    The dynamic mark. The shipped Code Team is seven zones on one model at seven temperatures: pp 0.15 is careful, ff 0.85 is inventive.

  5. 05

    Tools & permissions

    Web search, file reads, shell, terminals, MCP servers — enabled per zone, with its own approval policy. A scout that only reads and an implementer that may edit stop being the same policy.

Which is why seven zones on one model is a real answer and not a trick. The value comes from independent attempts and adversarial review, not from a bigger model.

Fine

Bring the whole section in.

Download the MSI or NSIS installer and run it. Windows 10 and 11 already ship the WebView2 runtime MultiZone needs, so there is nothing else to install. Then open Settings, add one provider, and create your first zone, or install a curated one from the library in a single action.

Get the latest release Source on GitHub

Free and Apache-2.0. There is no paid tier, no sign-up, and nothing to activate.

Before you send the first message

  1. Add a provider. Settings → any OpenAI-compatible endpoint plus a key.
  2. Create a zone pointing at it, or install one from the curated library.
  3. Add perspectives. Everything after that fans out to all of them.

Windows only, and pre-1.0. There is no macOS or Linux build today. Version 0.15.7 ships and is used daily, but it has not reached 1.0 and the release notes will tell you what changed under you.
