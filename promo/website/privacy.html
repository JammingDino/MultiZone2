Sotto voce.

— under the voice; quietly, and without hiding anything

Nothing is collected. Not as a policy: there is no server to send it to. That is an architectural fact rather than a promise, and the rest of this movement is the half a marketing page usually leaves out.

Collected

Noanalytics
Nocrash reporting
Nocloud sync

Chats, zones, settings and indexes live in one local SQLite file whose location Settings → Data shows you. What leaves the machine leaves because you sent it.

A message to a cloud provider

Straight to the endpoint you configured. Nothing in the middle.

A web search or page fetch

From your machine, to the engines. A query is a disclosure to every engine it fans out to.

A remote MCP server

Only the ones you enabled, only when connected.

An API-based voice endpoint

Point it at a local Whisper server and even this stays on the machine.

Two consequences worth stating rather than burying: a cloud model sees your files when a tool reads them, and a search query is a disclosure to the engines it reaches. Run a local model with no web tools and nothing leaves at all.

Stated,
not buried

bar 22

Two things a short version would gloss over.

The app checks for updates ~2.5 s after launch

A plain GET for a static manifest. No identifier, silent on failure. Settings → Data turns it off, and with it off, MultiZone makes no network request you did not start.

Provider API keys are stored in plain text

In that SQLite file. Not encrypted, not in the OS keychain. Treat the database as being as sensitive as the keys themselves.

The full statement is in docs/PRIVACY.md, and is also readable inside the app — Settings → Data → Read the privacy statement — without a network connection.

Limits

con verità

bar 40

What doesn't work, in the same voice as what does.

A tool that reports “I could not read this page” is worth more than one that returns an empty string. The same principle applies to a product page.

  • Windows only

    MSI and NSIS installers for Windows 10 and 11. There is no macOS or Linux build today. The stack is Tauri, so it is not impossible — it is not done.

  • Pre-1.0

    Version 0.15.7. It ships and is used daily, but it has not reached 1.0, and the release notes will tell you what changed under you.

  • Keys in plain text

    Stated above and repeated here because it belongs in both places. Signed-in connectors — OAuth with refresh, per-scope consent, tokens in the OS keychain — land after 1.0.

  • Pipes, not a PTY

    Terminals drive servers, build tools and REPLs. Full-screen TUIs and interactive ssh password prompts do not work. Pass sudo -S, and stop a process with terminal_stop rather than Ctrl-C.

  • No headless browser

    The web tools carry a real Chrome TLS fingerprint but do not execute JavaScript. A page that renders entirely client-side, or sits behind an interactive challenge, is reported as such rather than returned blank.

  • No speaker labels

    The OpenAI transcription endpoint does not diarize, and a guess at who was talking, presented as data, is worse than not offering it.

  • Hosted MCP tokens expire

    Google's access tokens last about an hour, so a Gmail connector is paste-again-when-it-expires until signed-in connectors arrive.

  • Sub-agents can't ask you

    While a leader is driving them, ask_user is suppressed — a question in a chat nobody is watching would wait forever. Decide approvals before a long run.

  • Free, Apache-2.0

    No paid tier, no sign-up, nothing to activate, and the source is on GitHub. There is no roadmap item that turns this into a subscription.

Fine

That's the whole score.

One prompt to every model you configure, a leader that can resolve them, tools that reach the web and your shell and your files, and nothing in the middle. Download the installer and run it — Windows 10 and 11 already ship the WebView2 runtime it needs.

Where your data lives

  1. One SQLite file. Chats, zones, settings, indexes, checkpoints. Settings → Data shows you the path.
  2. Connectors as JSON. Imported MCP entries land as files in the app's connectors/ folder.
  3. Your project directories. Untouched except where you allowed edits.

Back that file up and you have backed up everything. Copy it to another machine and MultiZone opens exactly where you left it — including the keys, which is the other half of storing them in plain text.
