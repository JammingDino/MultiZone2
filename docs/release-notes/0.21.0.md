## MultiZone v0.21.0

Unstuck, in your browser, and the first request is yours to see.

### Get unstuck
- If MultiZone can't start because the data on this machine was written by a newer build, the error now offers **Update now**. It installs the latest release from GitHub, and your data is left untouched.

### Open it your way
- **Open in your browser** (Settings → Phone & remote): MultiZone starts in the tray and opens in your default browser instead of a window. It is only reachable from this computer, with a one-time sign-in. The tray can still open the window.
- **Settings as a tab**: the new button next to ✕ turns Settings into a tab you can dock, split or float. Appearance → *Settings opens* makes that the default.
- **Search every setting**: type in the Settings search box, press Ctrl+F, or use Ctrl+K. A result jumps to the setting and highlights it.
- Clicking a chat now opens it in a new tab. Settings → Chat → *Clicking a chat* switches back to replacing the tab you're on.

### The first request is yours
- See every part of the system prompt with its size. Switch parts off per zone or for every zone, and view or copy the exact request before anything is sent (zone editor, or Context → *View the exact request*).
- **Lean** keeps only what a zone's tools need, which helps small local models.

### Phone and locks
- A proper phone layout: one tab at a time, with the chat list and workspace in drawers.
- **Unlock a locked chat from your phone** or a browser tab with its password. The unlock is just for that device.
- **Unlocked chats lock again** after 15 minutes without use, when the window goes to the tray, or when your phone's screen turns off. You can change this in Settings → Data → Chat locks.
- A paired phone can no longer watch a locked chat's reply as it streams.

### Also
- Skills and commands look like commands as you type them.
- Dialogs and menus now take the keyboard: shortcuts no longer act on the panes behind them, and Settings and the model pickers work fully from the keyboard.
- Fixed: sidebar text could turn slightly blurry after zooming a pane.
- The launch splash now uses your theme's background, glass and accent colour.

### Installing
| Installer | Description |
|-----------|-------------|
| `*_x64-setup.exe` | Windows installer |
| `MultiZone-*.apk` | Android — a remote for your computer, not a second app. Pair it under Settings → Phone & remote. |

Existing installs update themselves — see Settings → Data → Updates.
