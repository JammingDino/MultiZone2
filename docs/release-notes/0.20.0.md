## MultiZone v0.20.0

A big one: the whole window is now panes you can arrange, the app has proper themes, and much less needs setting up.

### The window is yours to arrange
- The sidebar, chats, files, plan, terminals and context are all panes: drag them anywhere, stack them as tabs, split them side by side, float them as windows, and the layout is remembered.
- Each pane has one header row, its tabs. Chat controls sit in the tab bar; everything else is in the pane's ⋯ menu. Close a workspace tab and get it back from that menu or the command palette (Ctrl+K).
- Full keyboard control: Ctrl+Arrow moves between panes, Ctrl+Shift+Arrow moves a pane, Ctrl+Enter zooms one, Ctrl+= / Ctrl+- / Ctrl+0 size them, Ctrl+Tab / Ctrl+1–9 / Ctrl+W for tabs, F6 between panes. Menus and the chat list work from the keyboard too. Ctrl+/ lists everything.
- The title bar can be Shown, Auto-hide or Hidden (Settings → Appearance).

### Themes for everyone
- Built-in themes, background gradients, and a cleaner glass mode, with sliders for blur and see-through. An optional see-through window shows your desktop behind the app.
- Your messages come as Bubble or Editorial, and a `/skill` you send now shows as a run under your message with whether it loaded.

### Less to set up
- Plan mode: type `/plan` to turn it on or off, use the switch in the Plan panel, and choose in Settings → Runs whether the model may enter it on its own (Ask first is the default). Plans are shorter.
- Zones can follow the chat's model, tool presets replace the checkbox lists, and your Claude Code skills, agents and MCP servers can be imported.
- Commands work anywhere in a prompt, and dropped folders glow in place.
- Agents can set up a project for you (name, icon, folder, default zone, approvals) and change any appearance setting, just by asking in chat.

### Also
- Lock a chat behind a password: the app password or one of its own (right-click a chat → Lock chat…). Locked chats stay out of search, export and agents. It is a lock, not encryption.
- The Files tree updates itself when files change.
- Scrolling up while a reply streams now stays where you put it, and "Jump to latest" only appears when you have actually scrolled away.

### Installing
| Installer | Description |
|-----------|-------------|
| `*_x64-setup.exe` | Windows installer |
| `MultiZone-*.apk` | Android — a remote for your computer, not a second app. Pair it under Settings → Phone & remote. |

Existing installs update themselves — see Settings → Data → Updates.
